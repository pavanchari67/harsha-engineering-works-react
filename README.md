# Harsha Engineering Works - React structure

This version adds a React/Vite JSX structure while preserving the original UI and DOM-based functionality.

## Structure
- `src/App.jsx` - React app entry
- `src/pages/Home.jsx` - original UI markup preserved exactly
- `src/pages/Client.jsx` - compatibility page entry
- `src/pages/Worker.jsx` - compatibility page entry
- `src/main.jsx` - React bootstrap
- `src/main.js` - original application logic (kept unchanged)
- `src/style.css` - original styles (kept unchanged)

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
